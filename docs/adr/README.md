# Architecture decision records

Short records of the decisions that shape Loomy. Each one states the context, the decision, its consequences and the alternatives considered. They are based on the code, `CHANGELOG.md`, `README.md` and `docs/MODEL_CATALOG.md`. The module-by-module reference is [`docs/DESIGN.md`](../DESIGN.md).

| ADR | Title | Status |
|---|---|---|
| [0001](0001-bash-3-2-no-runtime-dependency.md) | Bash 3.2 with no runtime dependency | Accepted (2026-09-24) |
| [0002](0002-english-strings-compiled-french-dictionary.md) | Interface strings in English, French compiled from a dictionary | Accepted (2026-09-27) |
| [0003](0003-model-catalog-as-data.md) | Model catalog as data | Accepted (2026-09-25) |
| [0004](0004-official-skills-only.md) | Official skills only | Accepted (2026-10-06) |
| [0005](0005-versions-stay-0x-until-joint-validation.md) | Versions stay 0.x until joint validation | Accepted (2026-09-24) |

A new decision gets the next number; a superseded one keeps its file and changes its status.
