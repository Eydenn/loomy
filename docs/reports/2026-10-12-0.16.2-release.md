# Loomy 0.16.2 Release Checks

Date: 2026-10-12. User requested the tree improvements, Linux CI correction,
official release and Homebrew upgrade. Release only after the Mac and Linux
checks succeed; no other project's application deployment is part of this work.
This report records the local pre-publication checkpoint. Remote validation and
publication records are linked below rather than inferred from local tests.

## Changes

- Native Codex root contexts provide observed model and effort updates. Head
  and recent-tail reads share the bounded lifecycle budget with child agents.
  Catch-up status is separate from model identity; invalidated evidence is
  cleared rather than replaced with a guessed routing model.
- Recoverable context revisions keep repeated clear/restore cycles observable
  after checkpoint loss or corruption. Repeated same-session compaction retains
  the original live ownership boundary. Freshness transitions retain their
  latest state across repeated catch-up cycles and bounded checkpoint recovery.
- Lead and return boxes are wider. Child boxes adapt to available width, keep
  four columns where they fit, wrap titles into fixed rows and reserve interior
  padding so labels cannot erase borders or collide with neighboring boxes.
- The macOS opener test matrix simulates only its platform-specific fixture.
  Separate Linux target, tmux success/failure and missing-terminal checks retain
  actual Linux branches without desktop app commands or skipped assertions.
- Slow-render backpressure coalesces queued timestamps without losing dirty
  state or reordering keys. Quit is handled before another expensive frame.

- Backpressure regressions: 8 passed on Bash 3.2, with a 1.4-second renderer,

  The unmodified watcher failed the same prompt-quit regression.
- Independent scoped review reproduced two context-invalidation defects and

- Independent backpressure review found no remaining P1/P2. A 1.6-second
  renderer retained recent timestamps and exited on quit in 1.024 seconds;

- Actual project diagram inspected visually: GPT-6.1-SOL/high recovered from
  its real root context, padded boxes and long task titles rendered coherently.
- Final runtime/version/test files frozen in an ordinary local clone for the
  Mac suite; byte comparison against the reviewed source passed.

## Release Gates

- Initial frozen Mac suite: 1422 passed, 9 failed. Eight failures exposed an
  uninitialized freshness note in standalone diagrams; one expected the old
  missing-model label. Both corrected with no assertions skipped. The revised
  frozen full Mac suite passed: 1431 passed, 0 failed.
- Additional real-project PTY checks recovered all expected model/task markers
  but exposed delayed quit handling when timer records outrun rendering. After
  correction, real-project refresh and clean quit passed. The final frozen full
  Mac suite passed: **1432 passed, 0 failed**. Candidate runtime, version and
  test files remained byte-identical to the validated ordinary clone.
- Actual Linux validation is required on the pushed candidate before
  promotion: [PR checks](https://github.com/Eydenn/loomy/pull/1/checks).
- Official publication is gated by those checks; canonical records are the
  [release](https://github.com/Eydenn/loomy/releases/tag/v0.16.2) and the
  [Homebrew formula](https://github.com/Eydenn/homebrew-tap/blob/main/Formula/loomy.rb).

## Limits

- Native tracking depends on the bounded local protocol adapter and correlated
  owner evidence, not a promise about arbitrary future Codex formats.
- A finished agent turn does not certify its work. No completion percentages,
  fabricated usage or linguistic acceptance are inferred.
- Source changes cannot hot-reload an already running watcher; restart only the
  watcher after upgrade, leaving active lead and agent processes intact.
